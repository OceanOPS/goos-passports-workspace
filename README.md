# GOOS Passports Workspace

A public Passports workspace for community discussions, feedback, issue tracking, and proposals related to GOOS Passports.

## Purpose

This repository provides a public space to:

- Report issues or ambiguities related to GOOS Passports
- Share feedback from users and partners
- Discuss use cases, concepts, and interpretations
- Propose improvements or evolutions of the Passports standard

## What this repository is for

- Issues and questions about GOOS Passports identifiers, metadata, and structure
- Discussions on scope, terminology, and alignment with existing standards
- Proposals and suggestions from the community

## What this repository is not for

- Application or API bug reports
- Implementation-specific code issues
- Private or operational support requests

## How to participate

- Use **Issues** for bug reports, questions, or concrete proposals
- Use **Discussions** for open-ended topics and exploratory conversations
- Please provide as much context as possible when submitting feedback

## Governance

This workspace is moderated by the OceanOPS team. Contributions are welcome and encouraged from the wider community.
